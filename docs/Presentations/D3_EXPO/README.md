# EXPO Poster and Video

The files for this folder are as follows:
* `AdNaturaVideo.mov`: A 2-minute video presentation for our project, played at our booth during the EXPO for passersby to watch.
* `AdNaturaVideoWithCaptions.mov`: The same video as the above, but with overlaid captions built into the video.
* `expo.pdf` - The poster as printed for the EXPO event.

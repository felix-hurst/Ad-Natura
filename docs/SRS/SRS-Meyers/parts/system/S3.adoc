=== (S.3) Interfaces
.Aiming Interface
image::images/aiming_diagram.PNG[alt="Aiming interface diagram", width=1000]
Players mouse draws a line with it and the character symbolizing the path in which the strike it will take from the character to the mouse. 

.Tool Selection Interface
image::images/tool_selection_diagram.PNG[alt="Tool selection interface diagram", width=1000]
Player presses the Number keys 1-3 to select or deselect the required tool. The highlighted tool will display its name, functionality, and a description.

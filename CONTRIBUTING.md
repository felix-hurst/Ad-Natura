# How to contribute

If you're interested in making Ad Natura bigger and better, you've come to the right place!

## Contribution guidelines
- Please ensure you follow our [Code of Conduct](https://github.com/felix-hurst/Ad-Natura/blob/main/CodeOfConduct.md)
- This project is created in Unity with editor version 6000.1.11f1
- Coding style includes:
  - Allman style indenting
  - PascalCase for files, classes, and functions
  - camelCase for variables
- Ensure commits are atomic (one feature per commit), and that each commit has an appropriate message attached
- Include comments in source code for any functions or blocks of code requiring explanation
- Ensure contributions work on the latest versions of Windows, Linux and Mac, as executable builds (not just in the Unity editor)
- When you are ready to submit your changes, please submit a pull request including details of improvements made and why

## Bug reporting
To submit a bug report, please open an Issue in our repository with the following information included:
- Your OS version and specifications, including CPU and GPU details
- Version of Ad Natura installed
- Detailed description of the issue
- Exact steps to reproduce the issue
- Any known workarounds for the issue

Thank you for your interest in contributing to our project!

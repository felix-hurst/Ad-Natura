# How to install and uninstall
This page will explain how to install and uninstall Ad Natura.

## Supported platforms
Ad Natura is supported on the latest versions of the following platforms:
- Windows
- Linux
- MacOS

## Steps to install
1. Go to our [Releases](https://github.com/felix-hurst/Ad-Natura/releases) page and download the latest release for your platform.
2. Extract the .zip file and place the extracted folder into a safe place on your computer.
3. Inside the folder, locate the executable file. This varies by OS.
  - Windows: `AdNatura.exe`
  - Linux: `AdNatura.x86_64`
  - Mac: `AdNatura.app/Contents/MacOS/AdNatura`
  - Note: On Mac, you will need to use `chmod` to give yourself execute permission.
4. Run the executable file to launch the game.
5. It is recommended to manually create a shortcut of the executable, and place the shortcut on your desktop.

## Steps to uninstall
1. Locate and delete the folder containing the game data and executable. (This is the same folder you initially extracted from the .zip file.)
2. Navigate to `C:/Users/<user>/AppData/LocalLow/`. Here, you can delete the `WardensOfTheWild` folder. (This folder contains logs generated by the game.) File path mentioned here is for Windows, and may vary on other operating systems.
3. Delete your desktop shortcut (if applicable).
